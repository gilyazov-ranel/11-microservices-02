
# Домашнее задание к занятию «Микросервисы: принципы»

Вы работаете в крупной компании, которая строит систему на основе микросервисной архитектуры.
Вам как DevOps-специалисту необходимо выдвинуть предложение по организации инфраструктуры для разработки и эксплуатации.

## Задача 1: API Gateway

Решение должно соответствовать следующим требованиям:

- возможность проверки аутентификационной информации в запросах,
- обеспечение терминации HTTPS.

Обоснуйте свой выбор.

Кроме того, Kong отличается высокой масштабируемостью и имеет активное сообщество, что позволяет быстро внедрять решение без необходимости создания собственных модулей для безопасности или маршрутизации.

## Задача 2: Брокер сообщений

Составьте таблицу возможностей различных брокеров сообщений. На основе таблицы сделайте обоснованный выбор решения.

Решение должно соответствовать следующим требованиям:
- поддержка кластеризации для обеспечения надёжности,
- хранение сообщений на диске в процессе доставки,
- высокая скорость работы,
- поддержка различных форматов сообщений,
- разделение прав доступа к различным потокам сообщений,
- простота эксплуатации.

Обоснуйте свой выбор.

### Ответ
| Решение       |Кластеризация | Хранение сообщений на диске | Скорость работы | Поддержка разных форматов сообщений | Разделение по ролям | Простота  эксплуатации |
|---------------|--------------|-----------------------------|-----------------|-------------------------------------|---------------------|------------------------|
|Apache Kafka   |Есть          | Есть                        |Очень высокая    |JSON, Avro, Protobuf	               |Есть                 |Требует настройки       |
|RabbitMQ       |Есть          | Есть                        |Высокая          |	JSON, XML, AMQP                    |Есть                 |Высокая|
|ActiveMQ       |Есть          | Есть                        |Средняя          |	JSON, XML, AMQP                    |Есть                 |Средняя|

Apache Kafka является наиболее подходящим решением для заданных требований, так как:
1. Поддержка кластеризации: Kafka поддерживает кластеризацию, что обеспечивает высокую доступность и надежность системы.
2. Хранение сообщений на диске: Kafka хранит сообщения на диске, что позволяет восстанавливать данные в случае сбоя.
3. Высокая скорость работы: Kafka обеспечивает очень высокую скорость обработки сообщений благодаря своей архитектуре и возможности параллельной обработки.
4. Поддержка различных форматов сообщений: Kafka поддерживает несколько форматов сообщений, включая JSON, Avro и Protobuf, что делает его гибким для различных приложений.
5. Разделение прав доступа: Kafka предоставляет возможность настройки ACL для управления доступом к различным потокам сообщений.
6. Простота эксплуатации: Хотя настройка Kafka может быть более сложной по сравнению с другими брокерами, его производительность и возможности масштабирования делают его более предпочтительным для крупных систем.
